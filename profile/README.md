### O que fazemos

- **Dados** · pipelines que reúnem as informações do ERP e de outras fontes num lugar só, prontas para análise.
- **Painéis e relatórios** · os indicadores do negócio em dashboards que se atualizam sozinhos.
- **Sistemas web e APIs** · aplicações e integrações feitas para o processo de cada cliente.
- **Sites** · presença digital rápida, clara e fácil de manter.

### Como trabalhamos

- **Padrões em todo projeto** · cada mudança é revisada e cada entrega vira uma versão numerada, com notas do que mudou.
- **Automação de ponta a ponta** · verificações automáticas a cada mudança e publicação sem passos manuais.
